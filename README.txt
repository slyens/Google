CHROME STYLE
============

Projet de navigateur avec une interface fortement inspiree de Google Chrome.

Installation :
1. Installe Node.js : https://nodejs.org/
2. Ouvre PowerShell dans ce dossier.
3. Lance : npm install
4. Puis : npm start

Fonctions :
- onglets
- nouvel onglet
- fermer un onglet
- precedent / suivant
- actualiser
- accueil
- barre d'adresse
- recherche Google
- vrais sites web

Ce projet n'est pas Google Chrome officiel.
